# Guppy 개인정보처리방침

**발효일: 2026년 5월 9일**

Guppy은 오프라인 로컬 음악 플레이어입니다. 모든 음악, 청취 기록, 개인 데이터는 사용자의 기기에 보관되므로 개인정보 보호가 Guppy 설계의 핵심입니다. 당사는 서버를 운영하지 않으며, 어떤 방식으로도 사용자의 데이터를 수집, 업로드 또는 공유하지 않습니다.

이 정책은 Guppy이 디바이스에서 액세스하는 항목, 액세스하는 이유, 사용자가 가진 제어 권한에 대해 설명합니다.

## 당사가 수집하지 않는 정보

Guppy은 다음 중 어느 것도 수집, 업로드 또는 당사 또는 제3자와 공유하지 않습니다:

- 계정 정보, 이름, 이메일, 전화번호 또는 개인 식별자.
- 디바이스 식별자, 광고 식별자 또는 위치 데이터.
- 음악 파일, 가사, 아트웍, 청취 기록, 즐겨찾기 또는 재생 목록.
- 사용량 분석, 원격 분석 또는 충돌 보고서.
- 결제 카드 번호, 청구지 주소, 은행 계좌 정보 또는 기타 결제 자격 증명.

Guppy은 타사 분석, 광고 또는 추적 SDK를 통합하지 않습니다.

## 장치에서 Guppy이 액세스하는 항목

Guppy은 사용자가 관련 기능을 적극적으로 사용할 때만 디바이스에서 다음 항목에 액세스합니다. 모든 액세스는 Apple의 시스템 권한 프롬프트에 의해 제어되며, 모든 작업은 기기에서 로컬로 이루어집니다.

### 로컬 음악 및 파일

- Guppy은 시스템 파일 선택기를 통해 명시적으로 선택한 경우에만 음악 또는 가사 파일을 읽습니다.
- Guppy은 **사용자가 명시적으로 선택한 파일에만 액세스할 수 있습니다**. 기기에 있는 다른 파일은 스캔하거나 읽지 않습니다.

### 사진

- 사진 라이브러리에서 아트웍이나 가사 이미지를 가져오도록 선택할 때만 Guppy이 사진 라이브러리에 액세스합니다.
- Guppy은 시스템 사진 선택기(PHPicker)를 사용하여 사용자가 선택한 특정 이미지에만 **접근 권한을 부여합니다**. Guppy은 전체 사진 라이브러리 액세스를 요청하지 않습니다.

### 로컬 네트워크

Guppy은 사용자가 명시적으로 활성화한 다음 기능에 대해서만 사용자의 로컬 네트워크를 사용합니다. 모든 연결은 로컬 네트워크 또는 사용자가 직접 구성한 대상으로 제한되며, 당사 또는 제3자에게 업로드되지 않습니다:

- **장치 간 전송**: 동일한 로컬 네트워크에서 Guppy을 실행하는 두 장치 간에 음악과 가사를 이동합니다.
- **휴대폰으로 브라우저 업로드**: 휴대폰에서 로컬 HTTP 서비스를 일시적으로 시작하여 동일한 네트워크에 있는 브라우저에서 파일을 업로드할 수 있도록 합니다. 이 서비스는 이 기능이 열려 있는 동안에만 실행됩니다.
- **WebDAV**: 음악을 찾아보거나 가져오기 위해 직접 구성한 WebDAV 서버에 연결합니다.
- **서브소닉 호환 서버**: 음악을 탐색하거나 가져오기 위해 직접 구성한 서브소닉 서버에 연결합니다.

입력하는 모든 서버 주소, 사용자 아이디, 비밀번호는 디바이스에만 저장되며(자격 증명은 시스템 키 체인에 보관됩니다) 절대 업로드되지 않습니다.

## 구매 및 구독

Guppy은 Apple의 인앱 구매 시스템을 통해 프리미엄 구독 옵션과 평생 1회 구매를 제공합니다. 모든 구매, 구독 결제, 갱신, 취소 및 환불은 App Store, iTunes 또는 Apple ID 계정을 통해 Apple에서 처리합니다.

Guppy은 결제 카드 번호, 청구지 주소, 은행 계좌 정보 또는 기타 결제 자격 증명을 수집, 수신, 저장 또는 처리하지 않습니다. Apple은 구독 또는 평생 구매가 활성 상태인지, 만료되었는지, 취소되었는지 또는 복원되었는지 여부와 같은 제한된 구매 상태 정보를 Guppy에 제공할 수 있습니다. Guppy은 프리미엄 기능을 잠금 해제하거나 복원할 때만 해당 구매 상태를 장치에서 사용합니다.

ITunes 또는 Apple ID 설정에서 구독을 관리하거나 취소할 수 있습니다. Apple의 구매 및 청구 정보 처리에는 Apple의 자체 개인정보 처리방침 및 App Store 약관이 적용됩니다.

## 타사 서비스

WebDAV 또는 서브소닉 서버에 연결하도록 선택하면 디바이스와 사용자가 구성한 서버 간에 데이터 교환이 이루어지며 해당 서비스의 자체 개인정보 처리방침이 적용됩니다. Guppy은 이러한 직접적인 상호 작용 이외의 데이터 수집이나 전달에는 관여하지 않습니다.

## 사용자의 책임과 음악 저작권

- Guppy은 이미 합법적으로 소유하고 있거나 사용 권한이 있는 로컬 음악만 **재생**합니다.
- Guppy **은 음악 다운로드, 검색 또는 배포 서비스를 제공하지 않습니다**. 모든 음악, 가사, 아트워크는 사용자가 직접 가져와야 합니다.
- 회원님이 가져오는 모든 음악, 가사 또는 아트웍에 대해 필요한 권리 또는 라이선스를 보유하고 있는지 확인할 책임은 전적으로 회원님에게 있습니다. 승인되지 않은 콘텐츠를 가져오거나 사용함으로써 발생하는 모든 결과에 대한 책임은 전적으로 회원님이 부담합니다.
