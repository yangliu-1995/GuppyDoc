# Guppy 개인정보 보호정책

**유효일: 2026년 4월 23일**

Guppy은 오프라인 로컬 음악 플레이어입니다. 개인정보 보호는 Guppy 설계의 핵심 부분입니다. 모든 음악, 청취 기록, 개인 데이터는 기기에 보관됩니다. 당사는 어떠한 서버도 운영하지 않으며 어떤 방식으로든 귀하의 데이터를 수집, 업로드 또는 공유하지 않습니다.

이 정책은 Guppy이 귀하의 장치에 액세스하는 대상, 액세스하는 이유 및 귀하가 갖는 제어권에 대해 설명합니다.

## 수집하지 않는 정보

Guppy 다음 항목을 수집, 업로드하거나 당사 또는 제3자와 공유하지 **않습니다**:

- 계정 정보, 이름, 이메일, 전화번호 또는 개인 식별자.
- 기기 식별자, 광고 식별자 또는 위치 데이터.
- 음악 파일, 가사, 작품, 청취 기록, 즐겨찾기 또는 재생 목록.
- 사용 분석, 원격 측정 또는 충돌 보고서.

Guppy은 타사 분석, 광고 또는 추적 SDK를 통합하지 않습니다.

## Guppy가 귀하의 기기에서 액세스하는 내용

Guppy은 관련 기능을 적극적으로 사용할 때만 기기의 다음 항목에 액세스합니다. 모든 접근은 Apple의 시스템 권한 안내에 따라 통제되며, 모든 일은 귀하의 기기에서 로컬로 이루어집니다.

### 로컬 음악 및 파일

- Guppy는 시스템 파일 선택기를 통해 명시적으로 선택한 경우에만 음악 또는 가사 파일을 읽습니다.
- Guppy은 **명시적으로 선택한 파일에만 액세스**할 수 있습니다. 장치에 있는 다른 파일은 검색하거나 읽지 않습니다.

### 사진

- Guppy는 사진 라이브러리에서 작품이나 가사 이미지를 가져오도록 선택한 경우에만 사진 라이브러리에 액세스합니다.
- Guppy는 시스템 사진 선택기(PHPicker)를 사용하여 Guppy에게 **선택한 특정 이미지**에만 액세스할 수 있는 권한을 부여합니다. Guppy 절대 사진 라이브러리 전체 액세스 권한을 요청하지 않습니다.

### 로컬 네트워크

Guppy는 명시적으로 활성화한 다음 기능에 대해서만 로컬 네트워크를 사용합니다. 모든 연결은 로컬 네트워크나 사용자가 직접 구성한 대상으로 제한됩니다. 당사나 제3자에게는 아무것도 업로드되지 않습니다.

- **기기 간 전송**: 동일한 로컬 네트워크에서 Guppy을 실행하는 두 기기 간에 음악과 가사를 이동합니다.
- **휴대폰에 브라우저 업로드**: 휴대전화에서 로컬 HTTP 서비스를 일시적으로 시작하여 동일한 네트워크의 브라우저에서 파일을 업로드할 수 있습니다. 이 서비스는 기능이 열려 있는 동안에만 실행됩니다.
- **WebDAV**: 음악을 찾아보거나 가져오기 위해 직접 구성한 WebDAV 서버에 연결합니다.
- **Subsonic 호환 서버**: 음악을 탐색하거나 가져오기 위해 직접 구성한 Subsonic 서버에 연결합니다.

입력한 모든 서버 주소, 사용자 이름, 비밀번호는 귀하의 기기에만 저장되며(자격 증명은 시스템 Keychain에 보관됨) 업로드되지 않습니다.

## 제3자 서비스

WebDAV 또는 Subsonic 서버에 연결하도록 선택하면 결과적인 데이터 교환은 귀하의 장치와 귀하가 구성한 서버 간에 이루어지며 해당 서비스의 자체 개인정보 보호정책이 적용됩니다. Guppy는 직접적인 상호작용을 넘어서는 어떠한 데이터 수집이나 전달에도 관여하지 않습니다.

## 귀하의 책임과 음악 저작권

- Guppy 이미 법적으로 소유했거나 사용 권한이 있는 로컬 음악만 **재생**합니다.
- Guppy **음악 다운로드, 검색, 배포 서비스를 제공하지 않습니다**. 모든 음악, 가사, 삽화는 귀하가 가져옵니다.
- 귀하가 가져오는 음악, 가사 또는 예술 작품에 대해 필요한 권리나 라이센스를 보유하고 있는지 확인하는 것은 전적으로 귀하의 책임입니다. 승인되지 않은 콘텐츠를 가져오거나 사용하여 발생하는 결과에 대한 모든 책임은 귀하에게 있습니다.
